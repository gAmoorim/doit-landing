# doit — Gerenciador de Tarefas

Organize sua rotina, priorize o que importa e mantenha suas tarefas sob controle com o Doit.

O Doit é um aplicativo desktop de gerenciamento de tarefas desenvolvido para oferecer uma experiência simples, intuitiva e visualmente limpa. Com interface em dark mode, filtros e organização por prioridade, o objetivo é facilitar o acompanhamento das atividades do dia a dia.

## ✨ Funcionalidades

- **Organização por status:** visualize e gerencie tarefas de acordo com seu estado.
- **Prioridades:** identifique as tarefas que precisam de mais atenção.
- **Filtros:** encontre atividades com mais facilidade.
- **Edição de tarefas:** crie e edite tarefas com feedback imediato.
- **Gerenciamento de conta:** disponibiliza opções para edição das informações do usuário.
- **Dark mode:** interface escura com foco em legibilidade e conforto visual.

## 🎨 Identidade Visual

A interface segue uma proposta minimalista e moderna, com foco na experiência do usuário.

- **Fundo escuro:** reforça a identidade do aplicativo e o uso do dark mode.
- **Rosa como cor de destaque:** direciona a atenção para elementos importantes.
- **Tipografia expressiva:** contribui para uma identidade visual consistente.
- **Componentes objetivos:** evitam excesso de elementos e distrações.

O projeto tem como objetivo apresentar o Doit de forma clara e profissional, destacando suas funcionalidades e oferecendo uma experiência de navegação simples para quem deseja conhecer ou baixar o aplicativo.
